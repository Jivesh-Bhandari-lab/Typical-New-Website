# Holy Kids Convent School Website

The official website for **Holy Kids Convent School**, designed to showcase our academic excellence, modern facilities, and vibrant school community.

## 🚀 Live Demo
Check out the live site here: [https://holy-kids-convent-school.netlify.app/](https://holy-kids-convent-school.netlify.app/)

## ✨ Key Features
- **Interactive UI**: Custom cursor effects and particle animations.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **Branch Information**: Detailed sections for both the Sangwari and Hardas (Hathras) branches.
- **Mission & Vision**: Dedicated 'About Us' page highlighting our educational goals.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Custom properties and animations)
- Vanilla JavaScript
